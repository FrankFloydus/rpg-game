## Stone and enemy surface pass · 2026-11-25

These seven diffuse textures used the built-in imagegen tool. Every generation included the existing Hearth Below texture as the edit target and the named visual swatches from the local Skyrim Special Edition texture archives as reference images. The installed-game swatches remain outside the project. The two Blender rigs and all exported runtime imagery use Hearth Below assets.

## Reference boundaries

- The installed Path of Exile client supplied base names, magic modifier labels, rare-title word and category weights, monster names and titles, pack and rarity records, identification commands, and loot filter or effect names. The available client and data did not establish authoritative server-side RNG order or every exact spawn and naming routine. Hearth Below uses original names and implements its own seeded rules. Grinding Gear Games' equipment frame dimensions were measured from publisher footage. The local executable confirmed inventory references. [Item format](https://www.pathofexile.com/developer/docs/reference#type-Item) · [Item filter and beams](https://www.pathofexile.com/item-filter/about) · [Publisher footage](https://store.steampowered.com/app/238960/Path_of_Exile/)
- Local Vermintide 2 evidence established shipped animation and action timing paths and a network animation-variable bound. The 1.60× gameplay cap and 0.34-second charge minimum are Hearth Below tuning. Local Skyrim textures informed original ImageGen material work. The shipped underwater movement model uses project-owned Godot code guided by id Software's published Quake movement and water-level handling. [Quake movement](https://github.com/id-Software/Quake/blob/master/WinQuake/sv_user.c) · [Quake water state](https://github.com/id-Software/Quake/blob/master/WinQuake/sv_phys.c)
- The project remains in GDScript. Existing typed resources, Godot scenes and editor tools carry most authored behavior. The current evidence identifies no measured whole-project C# benefit. [Godot language tradeoffs](https://docs.godotengine.org/en/stable/about/faq.html#which-programming-language-is-fastest)
- The goal and this document tracked progress. A recurring status automation was not created. The superseded global save generations were moved to the project-adjacent legacy backup. Named slots use their own directory.
